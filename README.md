# مِسبار — أداة تحليل المتاجر والمواقع بالذكاء الاصطناعي

موقع Responsive جاهز للنشر يستخدم Claude API لتحليل أي رابط متجر أو موقع وإرجاع تقرير عن:
التصميم والهوية، تجربة المستخدم، السيو والمحتوى، عناصر الثقة، وقابلية التحويل.

## هيكل المشروع

```
misbar/
├── index.html          الصفحة الرئيسية
├── assets/
│   ├── style.css        التصميم بالكامل
│   └── app.js            منطق الفحص والاتصال بـ API
└── README.md
```

المشروع **بدون أي backend أو build step** — ملفات ثابتة فقط (Static), تقدر تفتحه مباشرة
أو تنشره على أي استضافة ثابتة.

## كيف يعمل الفحص تقنيًا

1. المستخدم يدخل رابط الموقع، والأداة تجيب نسخة نصية من الصفحة عبر خدمة
   [Jina AI Reader](https://jina.ai/reader) (`https://r.jina.ai/<url>`) — مجانية ومفتوحة،
   وبتحل مشكلة CORS اللي بتمنع قراءة أي موقع مباشرة من المتصفح.
2. النص المستخرج يُرسل إلى Claude API (`claude-sonnet-4-6`) مع طلب صريح بإرجاع تقرير
   بصيغة JSON منظمة (نتيجة عامة، محاور، نقاط قوة وضعف، توصيات).
3. الواجهة تعرض النتيجة كداشبورد تفاعلي.

## تشغيل محلي

مفيش تثبيت مطلوب. افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`.

## مفتاح Anthropic API

الأداة تطلب من المستخدم مفتاح API خاص به (من [console.anthropic.com](https://console.anthropic.com)) ويُدخله
في حقل مخصص بالصفحة. المفتاح:
- يُستخدم مباشرة من المتصفح للاتصال بـ `api.anthropic.com`.
- يُحفظ في `localStorage` فقط لو المستخدم فعّل خيار "احفظ المفتاح في هذا المتصفح".
- لا يُرسل لأي سيرفر تاني غير Anthropic.

> ⚠️ **تنبيه أمني:** استخدام مفتاح API مباشرة من المتصفح مناسب لعرض تجريبي (demo) أو أداة
> شخصية. لو ناوي تطلق المنتج لعامة الناس بمفتاح واحد مشترك، الأفضل تعمل backend بسيط
> (مثلاً Cloudflare Worker أو Vercel Function) يستقبل الطلب من الواجهة ويستدعي Claude API
> من السيرفر، عشان المفتاح ميبقاش ظاهر في كود الموقع.

## النشر على GitHub Pages

1. ارفع الملفات لريبو جديد على GitHub.
2. من إعدادات الريبو → **Settings → Pages**.
3. اختار **Branch: main** والمجلد **/(root)**، ثم احفظ.
4. الموقع هيبقى متاح على رابط من نوع:
   `https://<username>.github.io/<repo-name>/`

## التخصيص

- الألوان والخطوط كلها معرّفة كـ CSS variables في أول ملف `assets/style.css`.
- محاور التحليل (الخمسة) تقدر تعدّل عددها ومحتواها من الـ `system prompt` في `assets/app.js`
  داخل دالة `runAnalysis`.
- النموذج المستخدم `claude-sonnet-4-6` — قابل للتغيير حسب احتياجك.

## الرخصة

استخدم الكود بحرية وعدّل فيه زي ما يناسب مشروعك.
