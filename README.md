# مِسبار — أداة تحليل المتاجر والمواقع بالذكاء الاصطناعي

موقع Responsive جاهز للنشر يستخدم Google Gemini API (مجاني عبر AI Studio) لتحليل أي رابط متجر أو موقع وإرجاع تقرير عن:
التصميم والهوية، تجربة المستخدم، السيو والمحتوى، عناصر الثقة، وقابلية التحويل.

## هيكل المشروع

```
misbar/
├── index.html          الصفحة الرئيسية
├── assets/
│   ├── style.css        التصميم بالكامل
│   └── app.js            منطق الفحص والاتصال بـ API
└── README.md
```

المشروع **بدون أي backend أو build step** — ملفات ثابتة فقط (Static), تقدر تفتحه مباشرة
أو تنشره على أي استضافة ثابتة.

## كيف يعمل الفحص تقنيًا

1. المستخدم يدخل رابط الموقع، والأداة تجيب نسخة نصية من الصفحة عبر خدمة
   [Jina AI Reader](https://jina.ai/reader) (`https://r.jina.ai/<url>`) — مجانية ومفتوحة،
   وبتحل مشكلة CORS اللي بتمنع قراءة أي موقع مباشرة من المتصفح.
2. النص المستخرج يُرسل إلى Google Gemini API (`gemini-2.5-flash`) مع طلب صريح بإرجاع تقرير
   بصيغة JSON منظمة (نتيجة عامة، محاور، نقاط قوة وضعف، توصيات)، باستخدام `responseMimeType: application/json`
   عشان نضمن رد JSON صافي بدون Markdown fences.
3. الواجهة تعرض النتيجة كداشبورد تفاعلي.

## تشغيل محلي

مفيش تثبيت مطلوب. افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`.

## مفتاح Google AI Studio (Gemini) — مجاني

الأداة تطلب من المستخدم مفتاح API خاص به من **Google AI Studio**، وهو مجاني:

1. ادخل على [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. سجّل دخول بحساب Google.
3. اضغط **Create API key** (تقدر تنشئه داخل مشروع Google Cloud جديد أو موجود).
4. انسخ المفتاح (يبدأ بـ `AIza...`) والصقه في حقل المفتاح بالصفحة.

المفتاح:
- يُستخدم مباشرة من المتصفح للاتصال بـ `generativelanguage.googleapis.com`.
- يُحفظ في `localStorage` فقط لو المستخدم فعّل خيار "احفظ المفتاح في هذا المتصفح".
- لا يُرسل لأي سيرفر تاني غير Google.

طبقة Gemini المجانية (Free tier) بتوفر عدد طلبات يومي كافي للتجربة والاستخدام الشخصي؛ لو
احتجت حجم استخدام أكبر تقدر تفعّل الفوترة (Billing) على نفس المفتاح من Google Cloud Console.

> ⚠️ **تنبيه أمني:** استخدام مفتاح API مباشرة من المتصفح مناسب لعرض تجريبي (demo) أو أداة
> شخصية. لو ناوي تطلق المنتج لعامة الناس بمفتاح واحد مشترك، الأفضل تعمل backend بسيط
> (مثلاً Cloudflare Worker أو Vercel Function) يستقبل الطلب من الواجهة ويستدعي Gemini API
> من السيرفر، عشان المفتاح ميبقاش ظاهر في كود الموقع.

## النشر على GitHub Pages

1. ارفع الملفات لريبو جديد على GitHub.
2. من إعدادات الريبو → **Settings → Pages**.
3. اختار **Branch: main** والمجلد **/(root)**، ثم احفظ.
4. الموقع هيبقى متاح على رابط من نوع:
   `https://<username>.github.io/<repo-name>/`

## التخصيص

- الألوان والخطوط كلها معرّفة كـ CSS variables في أول ملف `assets/style.css`.
- محاور التحليل (الخمسة) تقدر تعدّل عددها ومحتواها من الـ `system prompt` في `assets/app.js`
  داخل دالة `runAnalysis`.
- النموذج المستخدم `gemini-2.5-flash` — قابل للتغيير من ثابت `MODEL` في `assets/app.js` (مثلاً
  `gemini-2.5-flash-lite` للأسرع والأرخص، أو `gemini-2.5-pro` لتحليل أدق وأبطأ).
